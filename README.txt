# FocusDesk — Study & Productivity Website

## Files
- `index.html` — page structure
- `style.css` — colors, layout, and responsive design
- `script.js` — tasks, timer, notes, and reviewer checklist

## How to run it
1. Create a folder named `FocusDesk`.
2. Put all three files in the same folder.
3. Open `index.html` in your browser (double-click it).
4. To edit the website, open the folder in VS Code and edit the files.

## Features
- Dashboard with task statistics
- Add, complete, filter, and delete tasks
- Pomodoro focus timer with focus and break modes
- Quick notes that save automatically
- IT 312 Chapters 5–10 review checklist
- Responsive layout for desktop and mobile

## Saving your information
Tasks, notes, study checklist progress, and today's completed focus sessions are saved in your browser using `localStorage`. They stay on the same browser/device unless you clear browser data. This is a front-end demo; it does not sync across devices or have user accounts.

## Customizing
- Change text and page sections in `index.html`.
- Change colors and layout in `style.css` (look at the `:root` variables near the top).
- Change interactions in `script.js`.
